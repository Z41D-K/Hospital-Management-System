# 🏥 Hospital Management System

This is a simple hospital management system built in **C++**. It combines a **console-based menu** with **SFML-based welcome and goodbye screens** to make the experience a bit more interactive. The system helps manage patient records, diagnoses, discharges, and billing in a simple and organized way.Using oops basic concepts and implementing some basic secuirty features.

---

## Features

- **Secure Login:** Password input is masked with `*`.  
- **Wrong Attempt Handling:** Limits login attempts and enforces a wait time after multiple failed tries.  
- **Add New Patient:** Enter patient details and save them to a file.  
- **Add Diagnosis Information:** Record symptoms, diagnosis, medicines, and admission details.  
- **Discharge Patient:** Generate discharge summaries and billing details.  
- **View Full History:** See all saved information about a patient.  
- **About the Hospital:** Displays hospital info from a file.

---

## How it Works

1. Launch the program to see a **welcome screen**.
2. Login with a password (default is `"pass"`).  
3. Use the menu to manage patients, diagnoses, and discharges.  
4. Exit the program to see the **goodbye screen**.  
5. All data is stored in simple **text files**, making it easy to read and manage.

---

## Technologies Used

- **C++** – core programming and logic.  
- **SFML** – graphical welcome and goodbye screens.  
- **File I/O** – storing patient data in text files.  
- **Standard Libraries** – for input/output, strings, time, and exception handling.
